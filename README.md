# Senitukang Website

A portfolio and product showcase site for Senitukang, a Malaysian custom wood and acrylic craft studio. The visual direction uses an editorial portfolio layout with animated sections, selected-work galleries, product collections, and light/dark themes.

## Languages

- Bahasa Melayu (`ms`) is the default language.
- English (`en`) is available through the `BM / EN` switcher in the header and navigation overlay.
- The visitor's language choice is saved in browser local storage and persists while moving between Home and Products.

## Stack

- Next.js App Router
- React + TypeScript
- Tailwind CSS
- Motion for React animations

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

For a production build:

```bash
npm run build
npm run start
```

Product images are kept in `public/images/source/` and `public/images/work/`.
